# To-do list

一个轻量的 Windows 桌面待办工具：常驻桌面、托盘运行，支持截止时间、备注、完成历史、CSV 导出和开机自启。界面与数据全部本地化，不联网。

- **平台**：Windows 10 / 11 x64
- **安装包**：从 [Releases](https://github.com/835208148/To-do-list/releases) 下载 MSI
- **数据**：默认保存在 `%APPDATA%\To-do list\tasks.sqlite3`

## 功能特性

### 任务管理

- 在顶部输入框快速新建任务，回车即可添加。
- 为任务设置截止时间：可以选择「仅日期」或精确到分钟的时间（默认 09:00），也可以随时清除。
- 截止时间会显示在任务下方：当天截止显示「今天截止」，超时或过期显示「已逾期」。
- 勾选复选框完成任务，再次点击可恢复为未完成。
- 完成任务后会记录创建时间和完成时间，并显示在任务行与详情窗口中。
- 删除任务前会弹出确认；删除、完成、取消完成都可以在 8 秒内撤销。

### 列表与排序

- 三个视图：**当前**（未完成 + 今天完成）、**未完成**、**已完成**（今天完成），标签上实时显示数量。
- 拖动任务左侧的 `⠿` 手柄可以调整顺序。
- 任务标题过长会自动换行；备注在列表中显示首行摘要，点击可查看全文。
- 点击任务行（拖动手柄和复选框除外）会打开**事项详情**窗口，可查看完整备注、时间线，并进行编辑或删除。
- 编辑窗口支持修改任务名称、截止时间和多行备注。

### 完成历史

- 在「已完成」视图中点击「查看历史」，按完成日期分组浏览全部历史记录。
- 支持按关键词搜索任务名称和备注。
- 支持按完成日期筛选：**全部**、**今天**、**近 7 天**、**自定义起止日期**。

### 导出

- 在「设置 → 导出事项」中将任务导出为 CSV 表格。
- 可导出全部事项，或只导出某日期范围内完成的事项。
- 表头为：`事项`、`备注`、`截止时间`、`状态`、`完成日期`。
- 文件使用带 BOM 的 UTF-8 编码，可直接用 Excel 打开；以 `=`、`+`、`-`、`@` 开头的内容会自动加前缀，避免被表格软件当作公式执行。

### 窗口与托盘

- 关闭窗口（点击 `×`）不会退出程序，而是隐藏到 Windows 通知区域。
- 左键单击托盘图标重新打开窗口；右键菜单提供「打开」「窗口置顶」「设置」「退出」。
- 窗口置顶默认开启，可在托盘菜单中切换，状态会被记住。
- 点击标题栏的「收起」会把窗口折叠成一个可拖动的小图标（索隆头像），再次点击即可恢复。
- 窗口位置会被记住，重启后回到上次的位置；恢复窗口或折叠图标时，程序会把位置限制在当前显示器的工作区内。
- 程序为单实例：重复启动时会唤起已经运行的窗口，而不会打开第二个。

### 其他

- 支持开机自启：在「设置」中一键开启或关闭，写入当前用户的注册表启动项，无需管理员权限。
- 事项保存位置可查看、打开文件夹或更改；更改时会复制并校验数据库，原文件保留作为迁移前备份。
- 卸载时不会删除事项数据库和偏好设置。

## 下载与安装

1. 打开 [Releases](https://github.com/835208148/To-do-list/releases) 页面，下载最新的安装包，例如 `To-do-list-Setup-1.0.0-x64.msi`。
2. 双击运行安装向导，选择安装目录后完成安装。
3. 从开始菜单打开「To-do list」。

安装包为**当前用户安装**，不需要管理员权限，默认安装到：

```
%LOCALAPPDATA%\Programs\To-do list
```

安装程序会在开始菜单创建快捷方式，并支持版本升级（高版本会覆盖低版本）。

## 使用说明

### 新建任务

在窗口顶部的输入框中输入任务内容，按 `Enter` 或点击「添加」。输入框右侧的「截止时间」按钮可在添加前设置截止日期；添加后输入框和截止时间会自动清空。

### 设置截止时间

点击「截止时间」打开日期选择器：

- 「今天」「明天」可快速选择；
- 使用 `‹` `›` 切换月份；
- 选择「仅日期」表示截止到当天结束；选择「指定时间」可输入 24 小时制的小时和分钟；
- 最后点击「确定」；选择器左下角的「清除截止时间」可以取消截止时间。

### 完成、撤销与删除

- 点击任务左侧的复选框完成任务，再次点击恢复未完成。
- 完成、取消完成或删除任务后，窗口底部会出现撤销条，8 秒内点击「撤销」即可恢复。
- 在任务详情窗口中点击「删除」，确认后删除任务。

### 调整顺序

按住任务左侧的 `⠿` 手柄上下拖动，拖到目标位置后松开。排序只会在相同完成状态的任务之间进行。

### 查看完成历史

切换到「已完成」视图，点击右下方的「查看历史」：

- 顶部输入关键词可以搜索任务名称或备注，按 `Enter` 或点击「搜索」；
- 选择「全部」「今天」「近 7 天」或「自定义」筛选完成日期；
- 记录会按完成日期分组显示，并显示记录数量。

点击「‹ 返回」回到普通视图。

### 导出 CSV

打开「设置」（标题栏右侧齿轮图标），在底部点击「导出事项」：

1. 选择范围：全部事项、今天完成、最近 7 天完成，或自定义开始/结束日期；
2. 点击「导出 CSV」，选择保存位置；
3. 导出完成后会提示记录条数和文件路径。

按日期导出时，只包含该日期范围内**已完成**的事项。

### 收起与托盘

- 点击标题栏的「收起」：窗口折叠成一个小头像，可以拖动到任意位置，单击恢复窗口。
- 点击窗口右上角的 `×`：隐藏到托盘。
- 托盘图标左键单击：重新打开窗口。
- 托盘图标右键：打开窗口、切换窗口置顶、打开设置或退出程序。

### 设置

点击标题栏右侧的齿轮图标打开设置：

- **开机自启**：登录 Windows 后自动打开待办面板；
- **事项保存位置**：查看当前数据库路径，打开所在文件夹，或更改保存位置；
- **导出事项**：打开导出对话框。

## 数据存储与备份

### 默认位置

```
%APPDATA%\To-do list\tasks.sqlite3
```

即 `C:\Users\<用户名>\AppData\Roaming\To-do list\tasks.sqlite3`。

### 偏好设置

数据路径记录在：

```
%APPDATA%\To-do list\preferences.json
```

- 如果该文件存在，程序会使用其中 `database` 字段指向的数据库；如果文件指向的数据库不存在，程序会报错并提示恢复文件。
- 如果该文件不存在，且程序目录下存在 `tasks.sqlite3`（从旧版本或源码目录继承），则使用该文件；否则使用默认路径。
- 源码版和安装版共用这份偏好设置。

### 更改保存位置

在「设置 → 更改位置」中选择一个**不含** `tasks.sqlite3` 的文件夹：

1. 程序会在目标文件夹创建新的 `tasks.sqlite3`；
2. 使用 SQLite 备份接口复制当前数据，并执行 `PRAGMA quick_check` 校验；
3. 校验成功后写入 `preferences.json`，切换到新文件；
4. 原文件会保留在原位置，作为迁移前的备份。

如果目标文件夹已经存在 `tasks.sqlite3`，程序会拒绝操作，避免覆盖已有数据。

### 备份与迁移

- **备份**：从托盘退出程序后，复制 `tasks.sqlite3` 和（可选的）`preferences.json` 即可。
- **迁移到新电脑**：退出程序，把备份的 `tasks.sqlite3` 放到新电脑的 `%APPDATA%\To-do list\tasks.sqlite3`，再启动程序。
- 如果旧电脑改过保存位置，请同时迁移 `preferences.json`，或删除它让程序使用默认路径。
- 卸载程序**不会**删除事项数据库和偏好设置。

## 从源码运行

### 环境要求

- Windows 10 / 11 x64；
- Python 3.10 或更高版本（推荐使用官方安装包，自带 `tkinter` 和 `sqlite3`）。

项目运行时只使用 Python 标准库，不需要安装第三方依赖。

### 运行

```bash
git clone https://github.com/835208148/To-do-list.git
cd To-do-list
python Todo.pyw
```

使用 `python` 运行会保留控制台窗口；如果希望像安装版一样无控制台运行，可以使用 `pythonw Todo.pyw` 或直接双击 `Todo.pyw`。

首次运行时，如果程序目录下没有 `tasks.sqlite3`，会在 `%APPDATA%\To-do list\tasks.sqlite3` 创建数据库。

## 构建安装包

### 构建环境

- Windows x64；
- Python 3.14（构建脚本中已验证的版本）；
- .NET SDK（WiX 6 以 dotnet tool 方式运行）；
- WiX Toolset 6。

### 安装构建依赖

```powershell
python -m pip install -r requirements-build.txt
dotnet tool install --global wix --version 6.0.2
wix extension add --global WixToolset.UI.wixext/6.0.2
```

### 执行构建

```powershell
.\build.ps1
```

构建过程分两步：

1. 使用 PyInstaller 将 `Todo.pyw` 打包为 `build\app\To-do list\` 下的 onedir 程序，并附带 `one-piece.ico` 和 `zoro.png`；
2. 使用 WiX 将程序目录打包为 MSI，安装向导支持选择安装目录。

生成的安装包位于：

```
dist\To-do-list-Setup-1.0.0-x64.msi
```

`build\` 和 `dist\` 已加入 `.gitignore`，不会提交到仓库；安装包通过 GitHub Releases 分发。

## 数据库结构

程序启动时会自动创建表，并为旧数据库补齐缺失的列，无需手动迁移。

### `tasks`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER | 主键 |
| `title` | TEXT | 任务名称 |
| `done` | INTEGER | `0` 未完成，`1` 已完成 |
| `deadline` | TEXT | ISO 格式日期或日期时间，可为空 |
| `sort_order` | INTEGER | 排序值，越小越靠前 |
| `completed_on` | TEXT | 完成日期（`YYYY-MM-DD`） |
| `note` | TEXT | 备注，默认空字符串 |
| `created_at` | TEXT | 创建时间（`YYYY-MM-DD HH:MM:SS`） |
| `completed_at` | TEXT | 完成时间（`YYYY-MM-DD HH:MM:SS`） |

### `window_settings`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER | 固定为 `1` |
| `x` / `y` | INTEGER | 上次窗口位置 |
| `topmost` | INTEGER | 是否窗口置顶，默认 `1` |

## 常见问题

**点击 `×` 后程序不见了？**

程序没有退出，而是隐藏到了 Windows 通知区域。单击托盘图标即可恢复；右键托盘图标选择「退出」才会真正结束程序。

**托盘图标不见了？**

Windows 资源管理器重启后，程序会自动重新添加托盘图标。如果仍然看不到，请检查任务栏的「隐藏的图标」区域；也可以从开始菜单再次打开程序，它会唤起已运行的实例。

**重复打开程序会启动多个窗口吗？**

不会。程序是单实例的，第二次启动会把已有窗口带到前台。

**数据会上传到网络吗？**

不会。程序只读写本地 SQLite 数据库，没有任何联网代码。

**卸载会丢失事项吗？**

不会。卸载程序只删除程序文件，`tasks.sqlite3` 和 `preferences.json` 会保留。重新安装后可继续使用。

**安装包为什么比源码大很多？**

安装包使用 PyInstaller 打包了 Python 解释器和运行库，因此体积较大，但用户无需单独安装 Python。

**支持哪些系统？**

目前面向 Windows 10 / 11 x64。程序使用了 Win32 托盘、注册表和窗口相关 API，未在其他平台上测试。

**怎么关闭开机自启？**

打开「设置」，点击「开机自启」按钮即可关闭；也可以在任务管理器的「启动」选项卡中禁用 `ToDoListDesktop`。
